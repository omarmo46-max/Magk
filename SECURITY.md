# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately:

- GitHub: use *Security → Report a vulnerability* on this repository, or
- Telegram: [@O_P_E_2009](https://t.me/O_P_E_2009)

Include what you found, how to reproduce it, and the affected version/commit. You will get an
acknowledgement within a few days. Please give us reasonable time to fix the problem before
disclosing it publicly.

## Scope

In scope: the Android app, the sandbox (PRoot patches, offload client), backup/restore and
credential storage. Out of scope: vulnerabilities in third-party model providers, or issues that
need a rooted/compromised device.

## Supported versions

Only the latest build from `main` is supported.
